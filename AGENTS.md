# AGENTS

tool box for near kit with custom web client and reusable functions


---

### USING

two ways to use. you can use the fun and web packagae for building near dapps.

or you can use the fun and env package and create runable ts files for doing transactions or view only calls. the bin folder here already has bins you can run.

this project makes it easy to interact with near smart conratcs in a clean way, if the contract you want to interact with is not yet suppored feel free to contribute.
